# L3: USMTF ATO parser, work in progress

Lane L3, branch `lane/L3-ato-parser`. ADR: `docs/adr/0063-usmtf-ato-parser.md`. Code: `crc-sync/src/efsp/ato/`.
Tests: `crc-sync/tests/efsp-ato-*.test.mjs`. Fixtures: `crc-sync/tests/fixtures/ato/`.

## For the briefing (`docs/efsp-briefing.md`)

Suggested new paragraph under WP7 / §9.9:

> **ATO ingest (parser half, ADR 0063).** `crc-sync/src/efsp/ato/ato-ingest.js` turns USMTF ATO text into mission lines and creates nothing: no FDR, no Strip, no code. `ingestAtoText(text, { referenceUtc })` never throws. Each line has `fdrSeed` (only `createFdr` seed keys), `military` (`alertStatus`, `scl`, `arInfo`), `extras.{ato, identityAto}` and `warnings`, plus `lineId`, `sourceLines` and `provenance`. `ATO_FIELD_TARGETS` names the FDR path of every ATO value and whether anything can write it today. The ATO's Mode 3 is reported in `extras.identityAto.modeThree` and is never seeded as a beacon. The field layouts come from a community wiki and are cross-checked in `docs/parallel/research/usmtf-ato.md`; none is doctrine, and all of them are listed in ADR 0063. USMTF is the only input (H1).

## For the usage guide (`docs/efsp-usage-guide.md`)

Nothing user-facing yet: no import button exists until L14. When L14 lands, the guide should say:

- what the controller pastes (USMTF text, e.g. atobrief's export);
- that a line with a callsign over 7 characters (`DARKSTAR1`, `ENFIELD11`) needs a callsign typed before it becomes a Strip;

## For L14

- **Entry point:** `require('../efsp/ato/ato-ingest').ingestAtoText(text, { referenceUtc: missionClock.now() })`. Pass in-game Zulu (H11), not `Date.now()`. It is only used when the ATO has no `TIMEFRAM`.
- **Line shape** (S-Q50 + S-R2-8): `{ lineId, sourceLines, provenance, fdrSeed, military, extras: { ato, identityAto }, warnings }`.
  - `extras.ato.seedable === (fdrSeed.callsign !== null)`.
  - `extras.ato.callsign` is always the normalised callsign (H1), even when it cannot seed.
  - `extras.ato.missingAcceptanceFields` lists the WP7 fields the line lacks (`callsign`, `packageId`, `vulWindowStartUtc`, `vulWindowEndUtc`, `controllingAgency`, `modeOne`, `modeTwo`, `modeThree`), so you know when to fall back to callsign binding.
- **`new FdrStore().createFdr(line.fdrSeed, …)` accepts every seedable line.** Tested against both fixtures and the malformed one.
- **Hand-offs** (`ATO_FIELD_TARGETS` rows with `writePathToday: 'none'`):
  - mission type (`extras.ato.missionType`);
  - departure/recovery;
  - package commander;
  - IFF Mode 1/2 (`identity.modeOne`/`modeTwo` need a setter; `fdr-store.js` says "no setter exists anywhere");
  - the ATO's Mode 3 (the reconciliation of §3.10.3 rule 3, and ADR 0054's "does an ATO FDR mint a code");
  - datalink (`extras.identityAto.datalink`);
  - SCL (`military.scl`: `setMilitary` refuses it);
  - AMSNLOC altitude;
  - on-station time;
  - report-in point;
  - control type/frequencies;
  - `military.arInfo` (refused by `setMilitary`);
  - remarks (deliberately **not** `filed.remarks`).
- **`military.alertStatus`** can go through `setMilitary` today (`NONE`/`ALERT`).
- **Epoch-ms `mission.vulWindow*`**: Blocks `M6`/`M7` will render the raw number until you add a formatter (trap 14). A controller can also type free text into them (`WRITABLE_PATHS`).
- **Dates (R2-9, pending the human):** the epochs are resolved against the ATO's own `TIMEFRAM`. The raw DTG rides beside every time (`extras.ato.vulRaw`, `departure.raw`, `onStationRaw`, `arInfo.asReceiver[].arctRaw`, `targets[].raw`). Apply the ATO-date → mission-date policy to those.
- **ArLinks:** one per tanker/receiver pair, with `windows[]` for repeated ARINFOs. `resolved` is `BOTH` / `TANKER_ONLY` / `RECEIVER_ONLY` / `TANKER_NOT_A_MISSION` (atobrief's export gives tankers no mission number, so expect the last). No MARSA field, by design.
- **`MSGID … /CHG/`** gives info `ATO_CHANGE_MESSAGE`; amendment semantics are yours.
- **Agency types** live in `ato-sets.js` `CONTROL_AGENCY_TYPES` (H45): one line to add ABM/IC/RADAR.

## Deviations from the briefing

- **The research note wins** (supervisor addendum 2–3):
  - `9PKGDAT`/`PKGCMD` stay inside their missions, and `TSKCNTRY`/`SVCTASK` close missions.
  - The TACAN also accepts `39X`.
  - The CONTROLA RIP is **f5 by position** (`NAME:` only as a fallback), and f6 is kept as `comments`.
  - `PERIOD`/`PERID` are accepted as TIMEFRAM aliases (info), and `ATOCONF` with a warning.
  - A classification line before the first set is recorded as `header.classification`.
  - MSNACFT reads the 11-field [PROFILE] shape (`datalink.{l16Callsign,tacan,ju}`).
- **Primary fixture** is the research note's synthetic ATO, verbatim: `iron-flag-26-3.txt`. The briefing's `incirlik-day1.txt` is kept as a second fixture, with its `9PKGDAT` moved into `0101A` (the MC mission) and `PKGCMD` into `0103A`/`0102A`. Its line numbers therefore differ from §7.1, and the tests use the new ones.
- **Output keys** follow S-Q50/S-R2-8 (`fdrSeed`, `military`, `extras.{ato,identityAto}`), not the briefing's `seed`/`identityAto`/`ato`.
- **`AMSNDAT_VARIANT_A` instead of `AMSNDAT_VARIANT_B`**: the research note makes variant B the recommended reading, so the info marks the fallback (A), not the standard form.
- **IFF shape detection** is looser than the briefing's regex. The walk-back accepts any `[1-3]` + 2 or 4 digits, so `28888` is reported as `IFF_MALFORMED` (the §7.2 table requires that) instead of being taken for datalink.
- **Unterminated sets** also end where a line starting at column 0 with a *known* set name begins, not only at end of input. A missing `//` therefore no longer swallows the next set.
- **ArLink** gained `windows[]`, because L11's real export repeats ARINFO per refuel window.
- Extra warning codes:
  - `NO_TIMEFRAM`, `NO_MISSIONS`, `TIMEFRAM_ALIAS`, `ATOCONF_FORMAT`, `MSGID_NOT_ATO`;
  - `ZULU_ASSUMED`, `ALTITUDE_FORM`, `ALTITUDE_BLOCK`;
  - `PACKAGE_ID_CONFLICT`, `PACKAGE_COMMANDER_CONFLICT`, `PACKAGE_COMMANDER_INFERRED`;
  - `VUL_FROM_SEVERAL_TARGETS`, `VUL_FROM_7CONTROL`;
  - `AR_TANKER_NOT_IN_ATO`, `AR_TANKER_IFF_MISMATCH`.
- **§7.2 extras (defensible, allowed by the test):**
  - `TIME_UNRESOLVED` also fires on lines 8, 14 and 19. Those DTGs have a month but no year, or no month, and the ATO has no `TIMEFRAM`.
  - Info `AMSNDAT_VARIANT_A`, `NO_LOCATION_SET` and `NO_TIMEFRAM`.
- **The malformed fixture is stored with LF.** The repo's `.gitattributes` is `* text=auto`. The test converts it to CRLF before parsing, and the line numbers still match.
