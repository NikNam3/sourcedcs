## Disagreements recorded (briefing, research note and code)

- **The briefing's ojw1v5 oracle:**
  - it expected line 1 `CLASSIFIED` and the warning `CLASSIFICATION_NOT_UNCLAS`. H44 superseded both, so the
    line is now `UNCLAS` with `CLASSIFICATION_FORCED_UNCLAS`;
  - every other oracle line was recomputed against the trimmed file, and all hold.
- **The research note §4 suggested an ASOF derived from export time.** Not done (ADR 0078): there is no
  wall-clock ASOF, and it is only set explicitly through `header.usmtf.asof`.
- **The research note §4 said to refuse non-UNCLAS.** Replaced by H44.
- **Research §3 fixture layout vs the uniform rules** (briefing §5.4, expected):
  - `TIMEFRAM`, `AMSNDAT 1203S`/`1801W`, `MSNACFT`, `ARINFO` and `GTGTLOC` wrap at different points from the
    greedy rule;
  - `NO` and `OFLD` carry one space less than the column rule.

  The semantic test passes, and the renderer's byte golden is our own.
- **`yaml-format.md` documents `orbit.alt_ft`, but real packages put the altitude on the steerpoint.** Both are
  read, `orbit.alt_ft` first (T5).
- **`yaml-format.md` lists `registry.tankers` as a list, while the editor saves a dict.** Both are read (T3).

## Trim and anonymisation recipe (`ojw1v5-trimmed.yaml`)

Run `node atobrief/test/helpers/trim-ojw1v5.js /home/nklx/Downloads/ojw1v5.yaml`. It regenerates the file and
fails if any real callsign is left. The script:

1. **Keeps** `ato` first (the runtime shape), with `ingame_start_time`, `local_offset_hours`, `codewords`,
   `operation`, `classification` and `targets`. It **drops** `irl_date` and `irl_time_zulu`.
2. For each mission:
   - renames the callsigns: `RMBLE31`→`FALCN31`, `PRCVL11`→`HORNT11`, `LNCLT21`→`BLADE21`;
   - renames the unit `78th VMRS` to `TEST SQN`;
   - drops `dtc_cartridge`;
   - cuts each target's aim points to 2;
   - keeps only these steer points: one plain point, the `{id: MARSHAL-…}` ref, and the first orbit point.
3. Cuts `ato.targets` to the referenced ids (at most 2 aim points each).
4. From `spins`, keeps only the C3 table section, plus the section-level operation and classification.
5. From `registry`, keeps:
   - `callsigns`: the tankers, plus the 3 renamed flights (`RCKET11` is dropped);
   - `airfields.LTAG`;
   - `carriers`;
   - `tankers`: all 3, still a dict;
   - `targets`: the referenced ones, with 2 aim points each;
   - `steerpoints`;
   - `control_agencies`.
6. **Drops** `aco`, `comms`, `weather`, `registry.lines`, `registry.frequencies`, `registry.reference_points`
   and the other SPINS sections.
7. Keeps `classification: CLASSIFIED`, which exercises H44.

Checked with `grep -E 'RMBLE|PRCVL|LNCLT|RCKET|VMRS'` over every committed fixture: no hits.

## For L14

- **Endpoint:** `GET {atobrief}/api/rooms/{roomId}/ato.usmtf`, with `Authorization: Bearer ${ATOBRIEF_USMTF_TOKEN}`.
  - `text/plain` USMTF.
  - `?report=1` returns JSON `{text, warnings}`.
  - `If-None-Match` works against the `ETag`. `Last-Modified` is the time the presenter last loaded or saved.
  - `404` means no room or no package. `422` carries `{errors, warnings}` or a YAML error. `401` means bad auth.
- **Stateless:** `POST {atobrief}/api/usmtf` with `Content-Type: text/yaml` and the package YAML as the body
  (at most 1 MB).
- **Warning codes:**
  - gap infos, aggregated with a `missions` list: `PACKAGE_DATA_MISSING`, `IFF_MODE12_MISSING`,
    `IFF_MODE3_MISSING`, `DATALINK_MISSING`, `ALERT_STATUS_MISSING`, `RIP_MISSING`, `VUL_MISSING`,
    `AR_DETAIL_MISSING`, `SUPPORT_MISSIONS_NOT_EXPORTED`, `CALLSIGN_NOT_SEEDABLE`;
  - others: `CLASSIFICATION_FORCED_UNCLAS`, `AGENCY_TYPE_OTR`, `DEFAULT_UNIT`, `TIMEFRAME_DEFAULTED`,
    `TIMEFRAME_END_DERIVED`, `BAD_TIME`, `BAD_COORDS`, `BAD_TACAN`, `BAD_FREQUENCY`, `IFF_MALFORMED`,
    `IFF_RESERVED`, `IFF_NOT_STRING`, `IFF_ROW_UNMATCHED`, `IFF_SPINS_MISMATCH`, `UNKNOWN_TANKER`,
    `UNKNOWN_AGENCY`, `UNKNOWN_TARGET`, `UNKNOWN_SUPPORT_MISSION`, `MISSING_MISSION_NUMBER`,
    `DUPLICATE_MISSION_NUMBER`, `CHARSET_REPLACED`, `LINE_TOO_LONG`, and so on;
  - errors: `NOT_A_PACKAGE`, `NO_ATO_DATE`.
- **Rooms live in memory:** they vanish on close or restart (Q12).
