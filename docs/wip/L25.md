# L25: miztoyaml and the H43 fields (working notes)

Branch `lane/L25-miztoyaml-h43`. ADR `docs/adr/0089-miztoyaml-emits-support-missions-tacan-and-datalink.md`.
Scope: `tools/miztoyaml` only (S-R2-10).

## What was done

- **Tankers and AWACS are missions now.** Tankers are `REFUELING` and AWACS are `AEW`, with one mission per
  flight, numbered in flight order.
  - `registry.tankers[]` links to its mission through `mission_number`. Each entry also gets `freq_mhz`,
    `tacan`, `system` and `arcp`.
  - `registry.control_agencies.<cs>` links to its mission through `mission_number`.
- **TACAN** comes from the group's `ActivateBeacon` with type 4, for example `39Y`. It fills
  `registry.tankers[].tacan` and `missions[].datalink.tacan`.
- **Datalink:**
  - `datalink.l16_callsign` = the lead's `VoiceCallsignLabel` + `VoiceCallsignNumber`;
  - `datalink.ju` = the lead's `STN_L16`.

  Both are strings.
- **H60 callsigns** (`ato_callsign`, `tools/miztoyaml/build_missions.py`) are used for the missions, the
  registry keys, the steerpoint `flights` lists and the comms `callsign`. The comms `group` keeps the raw
  name.
- **S-L3:** `_random_squawk` never returns 6xxx.
- **Bug fix:** the group frequency was read with a flat search that hit a route beacon's `["frequency"]`
  (in Hz), so tankers showed 1112 MHz and similar. It now reads the group's own field (`_group_outer_text`).

## Defaults taken

- **`header.ato_date`** is still filled from the `.miz` date. H68 makes it irrelevant downstream, but
  atobrief's mapper refuses a package without it (`NO_ATO_DATE`), and it already equals the mission date.
  Nothing changed.
- **Mission numbering:** support flights take numbers in the same flight-order sequence as the others. Before,
  the others were numbered with the support flights skipped, so numbers shift in converted missions. There is
  no backwards compatibility, per the lane rules.
- **AR system** is taken from a DCS-type table (`TANKER_AR_SYSTEM` in `build_doc.py`). The `.miz` has no AR
  field, but the airframe fixes it. An unknown type leaves `system` out.
- **ARCP** is the orbit waypoint's name, upper-cased, when it has one. Otherwise it is left out, and atobrief
  falls back to the orbit steerpoint.
- **H60 when nothing fits:** matches L14's `fitCallsign` (WIP in the L14 worktree, `crc-sync/src/efsp/ato/callsign-fit.js`).
  - Vowels are cut from back to front, and the first character can be cut too.
  - When the name does not fit once every vowel is gone, the normalised name is emitted uncut, where L14
    returns null.
  - Cross-checked on 9 names against L14's function: identical.
- **Not emitted, because the `.miz` does not hold them:**
  - IFF Mode 1/2. The `.miz` has `IFF_M2_CODE = "auto"` on some modules, which is not an assignment;
  - Mode 3;
  - package id and commander;
  - alert status;
  - vul;
  - report-in point;
  - `offload_klb`;
  - a receiver's `refuel`;
  - `control.agency_id`.
- **Callsign registry:** AWACS stays out of `registry.callsigns`, as before. It is in `control_agencies`.

## Findings for other lanes and the supervisor

- **atobrief can still hand out 6xxx Mode 3 codes (S-L3).** `atobrief/public/js/editor/editor-spins.js`
  `_randomSquawkCode` excludes only 7500/7600/7700. This is outside L25's scope; it is a one-line fix
  (`code.charAt(0) === '6'`) for whoever owns atobrief next.
- **L14:** miztoyaml now emits callsigns that are already H60-fitted. The Python `ato_callsign` and
  `fitCallsign` are two copies of one rule: keep them equal.
- **`docs/atobrief/yaml-format.md` (atobrief's spec, not edited here)** should say:
  - miztoyaml fills the tanker `mission_number`, `tacan`, `freq_mhz`, `system` and `arcp`;
  - miztoyaml fills the agency `mission_number`;
  - missions carry `datalink` from the `.miz`;
  - `REFUELING`/`AEW` missions come from tanker/AWACS groups;
  - the IFF-squawk "Stale" note: miztoyaml emits no SPINS C3 (`spins.sections` is empty), and its unused
    generator skips 6xxx.
- **Dead code:** `build_spins_sections` in `build_doc.py` is tested but never called (`spins.sections: []`).
  Left as is.
