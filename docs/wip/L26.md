## What the usage guide should say

How to read an entry: `source: 'wire'` = refused before a store (written by the tap); `source: 'peer'`
= a replica change on this Facility's Board, `causedBy` = the other Facility's Mutation,
`clientMutationId: null`; `facilityId: null` = theater-wide (correlation, MARSA; MARSA names `fdrIds`);
`SetBlock` names `blockId`/`value`; coordination/TOFI entries name `action` (`CANCEL`, ...);
`SystemReassign` reason `position-vacated` vs `position-retaken`; `SystemCoordinationEnd` ends a link
whose replica was retired. A scramble cancelled on the ground is not counted as an alert scramble.
